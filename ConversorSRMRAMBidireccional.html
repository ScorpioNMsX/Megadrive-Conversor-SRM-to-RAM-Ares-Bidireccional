Mega Drive Conversor SRM ↔ RAM ↔ SaveRAM

By ScorpioN-MsX

Conversor entre .srm, Ares .ram y BizHawk .SaveRAM.

Selecciona un archivo.

Formatos usados para Mega Drive: Ares .ram = 8192 bytes compactos; .SaveRAM = 16384 bytes FF,dato; .srm = 512 bytes con los primeros 256 bytes útiles en patrón FF,dato.

Todo se procesa localmente en el navegador.
